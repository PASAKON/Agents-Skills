# Programmatic SEO — the 12 Playbooks (reference)

Source: **programmatic-seo** from `coreyhaines31/marketingskills` (MIT, Copyright (c)
2025 Corey Haines) — https://github.com/coreyhaines31/marketingskills . Loaded on
demand by `mooniex-seo` §7. See `../SOURCES.md` for full attribution.

Each playbook is a repeating keyword pattern you can template at scale. Always
apply the core rules first (unique value per page · proprietary data wins ·
subfolders not subdomains · genuine intent · respect the 30/50 doorway guardrail).

| # | Playbook | Pattern | Example |
|---|----------|---------|---------|
| 1 | Templates | `[type] template` | "invoice template", "resume template" |
| 2 | Curation | `best [category]` | "best CRM software", "best running shoes" |
| 3 | Conversions | `[X] to [Y]` | "USD to THB", "PDF to Word" |
| 4 | Comparisons | `[X] vs [Y]` | "Notion vs Obsidian" |
| 5 | Examples | `[type] examples` | "landing page examples" |
| 6 | Locations | `[service] in [city]` | "coworking spaces in Bangkok" |
| 7 | Personas | `[product] for [audience]` | "CRM for real estate agents" |
| 8 | Integrations | `[A] [B] integration` | "Slack Notion integration" |
| 9 | Glossary | `what is [term]` | "what is a pip in forex" |
| 10 | Translations | localized versions of a page | a tool page per language |
| 11 | Directory | `[category] tools` | "forex trading tools" |
| 12 | Profiles | `[entity name]` | per-broker / per-instrument pages |

**Layerable** — combine patterns for long-tail intent, e.g. "best coworking
spaces in San Diego" = Curation + Locations.

For each playbook page: keyword-matched header, a unique intro (not templated
boilerplate), data-driven sections, links to related pages (hub-and-spoke), and
an intent-appropriate CTA. Thin variants get `noindex`; everything indexable goes
in a type-split XML sitemap.
